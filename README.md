# HPC Task Status

独立的脱敏计算子任务状态数据仓库，供个人安卓监控 App 读取。

本仓库与现有集群监控网页相互独立，不向该网页提供数据。

## 数据文件

App 只读取 `data/status.json`，其固定结构如下：

```json
{
  "schema_version": 1,
  "updated_at": "2026-11-05T14:00:00+08:00",
  "timezone": "Asia/Shanghai",
  "collector_status": "ok",
  "tasks": [
    {
      "id": "subtask-001",
      "name": "子任务 001",
      "group": "任务组 A",
      "status": "success",
      "phase": "scf",
      "detail": "弛豫、电子自洽与能量记录均通过"
    }
  ]
}
```

状态字段仅使用以下值：

| 值 | 含义 |
| --- | --- |
| `success` | 弛豫收敛、电子自洽收敛且能量记录有效 |
| `warning` | 正常退出但未达到收敛，或完整性检查未通过 |
| `failed` | 明确异常终止或非零退出码 |
| `running` | 子任务运行中 |
| `pending` | 子任务等待中 |
| `unknown` | 状态无法确定 |

`collector_status` 为 `pending` 表示尚未收到首次真实采集，`ok` 表示采集成功，`error` 表示采集异常。

## 脱敏约束

- 不上传真实服务器名称、用户名、IP 地址或文件路径。
- 不上传计算输入文件、输出文件、日志、命令行或科研数据。
- 任务名称使用别名或编号；如需分组，仅使用不含研究内容的组名。
- GitHub 凭据仅保存在服务器本地，不进入本仓库或安卓 App。
- 本仓库为公开仓库，新增字段前必须确认其可以公开。

## 推送计划

采集端计划按北京时间每天 08:00、10:00、12:00、14:00、16:00、18:00、20:00 更新，共 7 次。

采集端位于服务器用户主目录的顶层 `server/`，每次动态读取任务清单，不固定子任务数量。`tasks.json` 中的私有路径和真实任务结构不上传到本公开仓库。

- `collect_status.py`：读取 VASP 输出，当前目录优先，历史目录仅补齐当前未开始的结果；
- `push_status.py`：对公开字段、名称、状态和说明文字执行白名单检查，推送后回读验证；
- `sync.sh`：加锁采集并推送，失败时保留本地快照；
- `install_cron.sh`：保留原有定时任务，只更新本监控的标记区块；
- `github.env`：仅服务器本地保存，权限 600，禁止公开上传。

状态是计算程序收敛与完整性的技术判定，不代替对物理模型和科学结论的人工审查。
